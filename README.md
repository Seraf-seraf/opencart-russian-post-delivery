# Russian Post Delivery for OpenCart 3

Расширение доставки Почтой России для OpenCart 3 с официальным ECOM-виджетом выбора отделения и расчётом тарифа через API сервиса «Отправка».

## Возможности

- выбор отделения Почты России, дополнительного ПВЗ или почтомата на карте;
- расчёт стоимости и срока доставки после выбора отделения;
- сохранение выбранного отделения и тарифа в заказе;
- отдельная вкладка с данными доставки в административной карточке заказа;
- использование веса и габаритов товаров из штатных полей OpenCart;
- общие значения веса и габаритов для товаров, у которых эти поля не заполнены;
- хранение AccessToken, логина и пароля API в настройках OpenCart;
- установка без OCMOD-модификаций системных файлов и без сторонних PHP-зависимостей.

## Требования

- OpenCart 3.x;
- PHP 7.4 или новее с расширением cURL;
- HTTPS на витрине;
- настройка ECOM-виджета Почты России;
- доступ к API сервиса «Отправка».

## Установка

Соберите установочный архив из корня репозитория:

```bash
zip -r opencart-russian-post-delivery.ocmod.zip upload
```

Затем в административной панели OpenCart:

1. Откройте `Расширения → Установка расширений`.
2. Загрузите `opencart-russian-post-delivery.ocmod.zip`.
3. Откройте `Расширения → Расширения`.
4. Выберите тип расширения `Доставка`.
5. Установите `Почта России`.
6. Откройте форму настройки, заполните обязательные поля и включите расширение.

При установке расширение создаёт таблицу `russian_post_order`, начальные настройки и необходимые события OpenCart. При удалении события и настройки удаляются, но таблица с данными оформленных заказов сохраняется.

## Настройка

Форма находится в разделе:

`Расширения → Расширения → Доставка → Почта России`

Обязательные поля:

- `ID ECOM-виджета` — значение `settings_id` из настройки виджета или его запроса к `widget.pochta.ru`;
- `Индекс отправителя` — шестизначный индекс места отправки;
- `URL API` — по умолчанию `https://otpravka-api.pochta.ru`;
- `AccessToken`, `Логин API`, `Пароль API` — доступы сервиса «Отправка»;
- `Вес по умолчанию` и `Габариты по умолчанию`;
- `Таймаут`, `Порядок сортировки` и `Статус`.

Секретные значения сохраняются в базе данных OpenCart. При повторном открытии формы они не выводятся: пустое поле при сохранении оставляет ранее записанное значение без изменений.

## Вес и габариты

Расширение использует штатные числовые поля товара:

`Каталог → Товары → Данные → Длина / Ширина / Высота / Вес`

Значения автоматически переводятся из выбранных в карточке товара единиц в сантиметры и граммы. Если отдельное значение равно нулю, применяется соответствующее значение по умолчанию из настроек доставки.

Заполнять габариты каждого товара не обязательно, но индивидуальные значения дают более точный расчёт тарифа. Текстовые значения со вкладки `Атрибуты` не разбираются, поскольку их формат и единицы измерения не стандартизированы OpenCart.

Для корзины длина и ширина упаковки определяются по наибольшему товару, а высота складывается с учётом количества товаров.

## Формат данных виджета

ECOM-виджет получает габариты как массив объектов:

```json
{
  "dimensions": [
    {
      "length": 15,
      "width": 10,
      "height": 5
    }
  ]
}
```

Формат `[15, 10, 5]` не поддерживается API виджета и приводит к ответу `422 Bad arguments`.
